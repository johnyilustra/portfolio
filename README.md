# Portfólio pessoal — pronto para GitHub Pages

## Para publicar
1. Extraia o ZIP.
2. Crie um repositório no GitHub.
3. Faça upload de TODO o conteúdo extraído para a raiz do repositório.
4. O index.html, assets e projects precisam aparecer na página principal do repositório.
5. Settings > Pages.
6. Deploy from a branch.
7. main + /(root).
8. Save.

## Para editar
Procure por SEU NOME, SN e seuemail@exemplo.com no index.html.

## Artes
Coloque suas artes em assets/images/projects/ e altere os caminhos src no HTML.

## Projetos internos
Duplique projects/projeto-template.html para criar um case novo.
