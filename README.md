# Portfólio pessoal — GitHub Pages

## Visualizar
Abra index.html no navegador.

## Editar
Troque SEU NOME, SN, seuemail@exemplo.com e os links das redes sociais.

## Artes
Coloque suas imagens em assets/images/projects/ e atualize os src no HTML.

## Cases
Duplique projects/projeto-template.html e renomeie para cada projeto.

## GitHub Pages
1. Crie um repositório.
2. Envie o conteúdo do ZIP para a raiz.
3. Settings > Pages.
4. Deploy from a branch.
5. main + /(root).
6. Salve.
